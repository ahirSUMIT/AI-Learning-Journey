\# AI Resume Parser



An AI-powered ATS Resume Screening System built using Python, Groq API, and Pydantic.



\## Features



\- Parse Job Descriptions

\- Parse PDF/DOCX Resumes

\- Structured JSON Output

\- Candidate Ranking

\- ATS-style Resume Matching



\## Technologies



\- Python

\- Groq API

\- Pydantic

\- PyMuPDF

\- python-docx



\## Run



```bash

pip install -r requirements.txt

python day7/resume\_parser.py

```
